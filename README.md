# Mustang Karyotype Lab

An interactive, auto-graded Biology game for **Standard 2.1: Chromosomes and Karyotyping (HS-LS3-1)** at Little Chute High School.

Students learn through short, gated lessons full of animations, games, and quick checks, then show evidence of proficiency in auto-graded Prove It rounds:

- **Level 1 · Trainee:** I can differentiate between chromatin and a chromosome.
- **Level 2 · Technician:** Additionally, I can define a karyotype and explain how one is used to identify genetic traits.
- **Level 3 · Cytogeneticist:** Additionally, I can create or interpret a karyotype to identify a genetic trait that may result.

Includes My Notes (open-note notebook that unlocks as students learn), Marty the Mustang lab assistant with capped hints, an Arcade (Vocab Invaders, Chromo Catapult, Telomere Trouble, Chromo-Wordle, Connections), active-time tracking, and a credential report students screenshot and turn in on Google Classroom.

## Hosting

It's a single static file (`index.html`) with no build step. On Vercel, import this repo with the **Other** framework preset and leave the build settings empty.

Progress is saved in each student's browser (localStorage) on the device they use.
